# LeetCode Java

The LeetCode solutions live directly in this folder as standalone Java files. Each file has a unique class name, imports, and a small `main` method so it can be run locally from VS Code or from the command line.

Run the default example:

```sh
./scripts/run.sh
```

Run a specific class:

```sh
./scripts/run.sh LargestRectangleInHistogram
./scripts/run.sh KeysAndRooms
./scripts/run.sh Codec
```

Shared local models for LeetCode-provided types are in `LeetCodeModels.java`.
